# Authentication Configuration

## Views Implemented
- login_view: User authentication with session management
- register_view: New user registration with validation
- logout_view: Secure logout functionality
- home_view: Protected page requiring login

## URL Routes
- / - Login page
- /register/ - Registration page
- /logout/ - Logout
- /home/ - Home page (login required)

## Features
- Django built-in authentication system
- CSRF protection
- Session-based authentication
- User validation and error handling
